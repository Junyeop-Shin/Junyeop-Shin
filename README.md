### 안녕하세요, 신준엽입니다 👋

사람과 상황을 관찰해 문제를 찾고, 그걸 서비스로 만드는 일을 합니다.
국어국문학을 전공하고 데이터융합서비스디자인을 복수전공했으며, 현재 SK AX의 AI 엔지니어 교육과정 **SKALA**에서 풀스택·AI 개발을 공부하고 있습니다.

기획에서 출발했기 때문에 코드보다 먼저 **문제 정의 → 요구사항 → 설계 판단 → 검증**을 문서로 남기는 것을 중요하게 생각합니다.
